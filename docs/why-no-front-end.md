# Why there is no front end

A packaging register is movements, quantities, counterparties and evidence. Ask the coding agent to inspect those records, reconcile a count or draft a statement. Every action uses the same CLI and every report uses the same database.

The free base includes read-only HTML snapshots and printable documents. It has no scanner, mobile capture, offline dispatch workflow, shared partner portal, automatic carrier feed or electronic signatures. A screen can make physical handovers quicker; a local assistant cannot replace a warehouse device. TrackOnline provides mobile and connected workflows beyond this register.

If dispatch relies on these facilities, keep them running until the replacement integration is tested. Enterprise DNA can build the phone capture, partner access and system connections into a scoped version. That is delivery work, not an included capability of the free base. No serialised asset tracking, rental billing or automatic food-safety release is claimed here.
