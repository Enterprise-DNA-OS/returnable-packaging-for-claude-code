## Scope and claims

[TrackOnline introduction](https://trackonline.com/how-to-get-started-with-trackonline/) describes transaction types, counterparties and downloadable dockets. [Smart Balance](https://trackonline.com/new-smart-balance/) documents configurable balance views and Excel export. TrackOnline already supports reports and configurable analysis. The ten example questions in this build are demonstrated queries, not an unverified claim the incumbent cannot answer them.

[TrackOnline Connect](https://trackonline.com/3-2-1-connect-get-started-with-trackonline-connect/) is a partner collaboration service. This project does not reproduce that network or promise automatic counterpart acceptance. The standalone ledger is useful for an operator with their own records, without OAuth or third-party access.

The vendor pricing page distinguishes intake/issue, location balances, integrations and configurable finance. The free base ships the register, explicit return allocations, count reconciliation and evidence checks. No rental billing, IoT, RFID, e-CMR or automatic data feed is claimed. Review evidence sources and import detail in the adjacent guides.

The registry already contained more than 200 categories. Neither TrackOnline nor returnable-packaging was registered. Tonight's previous access-governance build was excluded. No new customer name or private information is in this project.
