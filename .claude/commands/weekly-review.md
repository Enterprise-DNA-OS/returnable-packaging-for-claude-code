# weekly-review

Read CLAUDE.md and docs/cli.md. Prepare the weekly packaging review from balances, returns and evidence.

1. Read the relevant current records first. Resolve names with the CLI; present ambiguity instead of guessing.
2. Run the read or local-output command below.
3. Run: `npm run packaging -- weekly-review --json`.
4. Also run returns-due, balances and compliance separately. Summarise overdue units, owners, unresolved discrepancies and the next physical checks.
5. Never send a statement, email or message. Drafts remain local. Never infer physical handover from a database entry.
